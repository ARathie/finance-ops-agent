Disconnecting from QuickBooks

About · Connecting · Disconnecting · Licence · Privacy

The connection can be ended at any time, from either end, and nothing about the agent resists it.

From QuickBooks

In QuickBooks Online: Settings → Manage apps (or Apps → My apps), find this app, and choose Disconnect. Access stops immediately. The agent notices at its next run, stops trying, and emails Icon Technologies' administrator to say the connection needs renewing.

From the agent

Icon Technologies' administrator deletes the stored token file on the server. The agent then has nothing to connect with and says so the next time it runs.

What happens to the data

Invoices already created stay in QuickBooks, as any accounting record does — disconnecting an application does not undo bookkeeping. The agent's own records stay on Icon Technologies' server under the retention described in the privacy policy. To have those removed as well, write to kevin@icon-technologies.com.
