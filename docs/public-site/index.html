Icon Technologies billing agent

About · Connecting · Disconnecting · Licence · Privacy

This is internal software built and operated by Icon Technologies for its own billing. It is not a product, it is not offered to anyone else, and there is nothing here to sign in to.

The agent reads timesheets that consultants email to an Icon Technologies mailbox, checks them, prepares the matching client invoice in Icon Technologies' QuickBooks Online company, emails that invoice to the client with Icon Technologies' administrator copied, and tells the administrator what each consultant is owed. It never pays anyone and never moves money.

It runs by itself on a server Icon Technologies controls. It has no web interface, no user accounts, and no public endpoint: it makes outgoing connections only, and the single QuickBooks company it connects to is Icon Technologies' own.

Why this site exists

Intuit asks every application that connects to QuickBooks Online for a public licence agreement, privacy policy, and pages describing connecting and disconnecting, whether or not the application has customers. These pages are those. The privacy policy is the substantive one: it says what information the agent handles and which services it is shared with.
