Connecting to QuickBooks

About · Connecting · Disconnecting · Licence · Privacy

Only Icon Technologies connects this agent, and only ever to Icon Technologies' own QuickBooks Online company. There is no sign-up, and no way for anyone else to connect it to theirs.

How it is done

Icon Technologies' administrator runs fops qbo-connect on the server the agent runs on. That opens Intuit's own sign-in page in a browser; the administrator signs in as Icon Technologies and approves the connection. Intuit sends the result back to a one-time listener on the server's own loopback address, and the agent stores the company id and the resulting tokens on that server, readable only by the account the agent runs as.

The same command reconnects it. Connections need renewing if the agent has not run for an extended period, and the agent warns the administrator by email before that happens rather than waiting to fail.

What it asks for

Accounting access, which is what it needs to look up customers and products, create invoices, and read whether an invoice has been paid. Nothing else.
