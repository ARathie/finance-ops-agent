Privacy Policy

Icon Technologies billing agent · Effective 16 September 2026

About · Connecting · Disconnecting · Licence · Privacy

This policy describes how the Icon Technologies billing agent (“the agent”) handles information. The agent is internal software built and operated by Icon Technologies for its own billing. It is not offered to the public, it has no accounts for outside users, and nobody outside Icon Technologies signs in to it.

What the agent does

The agent reads timesheets that consultants email to an Icon Technologies mailbox, checks them, prepares the matching client invoice in Icon Technologies’ QuickBooks Online company, emails the invoice to the client with Icon Technologies’ administrator copied, and tells the administrator what each consultant is owed. It never pays anyone and never moves money.

Information the agent handles

  • Timesheets and the emails carrying them — the sender’s address, the subject, the message text, and the attached documents. A timesheet typically names a consultant, the client they worked for, the dates worked, the hours, and whoever approved them.
  • Business contact details — the names and email addresses of consultants, of client billing contacts, and of Icon Technologies’ administrator.
  • Commercial terms — the rate charged to each client, the rate paid to each consultant or their company, and payment terms. These are Icon Technologies’ own business records.
  • Invoices — the invoice number, dates, hours, rate, amount, and the resulting record in QuickBooks Online.

The agent does not handle bank details, payment card numbers, government identifiers, or any special category of personal data. It is not designed to receive them, and nothing in it asks for them.

Where the information comes from

From email sent to Icon Technologies’ own mailbox by consultants and by client managers approving work; from a spreadsheet Icon Technologies maintains listing its clients, consultants and engagements; and from Icon Technologies’ own QuickBooks Online company.

Who it is shared with

The agent uses a small number of service providers to do its work. It shares with each of them only what that service needs:

  • Anthropic — timesheet documents and the text of the emails carrying them are sent to Anthropic’s API so that its model can read them and report what they say. Consultant and client names are also sent, so that names on a document can be matched to the right spelling. Rates and email addresses are not sent. Anthropic processes this in order to return a reading, and under its commercial API terms does not use it to train its models.
  • Intuit (QuickBooks Online) — the client’s name, the consultant’s name, the billing period, the hours, the rate and the invoice total, in order to create the invoice in Icon Technologies’ own QuickBooks company.
  • Rackspace — hosts the mailbox the agent reads and sends from, so it holds the emails in the ordinary way an email provider does.
  • The provider of Icon Technologies’ backup storage — holds the nightly backup archives described below.

Information is not sold, rented, or shared for advertising. There is no advertising, no analytics, and no tracking of any kind in the agent.

Who receives email from the agent

Only two kinds of recipient. Icon Technologies’ administrator receives every email the agent writes. A client’s billing contact receives the invoice for that client’s own work, with the administrator copied on every one. The agent writes to nobody else.

Where it is kept, and for how long

The agent stores its records — the timesheets it has read, the invoices it has prepared, and its own working notes — in a database and file store on a server Icon Technologies controls, reachable only by Icon Technologies. Backups are written nightly to storage Icon Technologies controls: daily backups are kept for 90 days, and the first backup of each month is kept indefinitely, because invoices are financial records that Icon Technologies is required to retain.

How it is protected

The server accepts no inbound connections other than administrative access by cryptographic key. Credentials are held in environment settings readable only by the account the agent runs as, never in its source code and never in its logs. The agent’s logs deliberately exclude email bodies, attachment contents, rates and amounts. Connections to every service above are encrypted in transit.

Questions, and requests about your information

If you are a consultant or a client contact and you want to know what the agent holds about you, or want it corrected, write to kevin@icon-technologies.com. Icon Technologies will respond within a reasonable period. Where Icon Technologies holds your information on behalf of a client company under a contract with that company, it will also tell that company about your request.
