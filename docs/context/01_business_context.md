# Icon Technologies — Business Context

## Company Overview

Icon Technologies is an IT consulting and staffing business.

Historically, the company operated across four main business areas:

1. **Staffing and placement**
   - Finding and placing consultants or contractors for client companies.
   - This is the primary business activity that remains active today.

2. **Custom application development**
   - Building or enhancing software applications for clients.

3. **Enterprise software integration**
   - Connecting systems such as PeopleSoft and SAP.
   - Moving data between systems or exposing data through interfaces.

4. **Data enhancement and extraction**
   - Cleaning, enriching, matching, scraping, and exporting data.

The current project is focused only on the **staffing and placement business**, specifically the operational workflow that happens after a consultant is already working for a client.

## Current Staffing Model

Icon currently services existing clients rather than aggressively acquiring new ones.

A typical staffing relationship looks like this:

- A client has a staffing need.
- Icon identifies a consultant.
- The consultant may be:
  - an Icon W-2 employee,
  - an independent contractor,
  - or an employee/contractor of another consulting company that subcontracts through Icon.
- The consultant performs work for the end client.
- The end client pays Icon.
- Icon pays the consultant or consulting company.
- Icon earns the difference between the client bill rate and the consultant pay rate.

There can be multiple layers in the staffing chain. For example:

`End Client -> Primary Vendor -> Icon Technologies -> Consultant / Subcontracting Company`

Not every engagement has the same structure.

## Current Scale

Icon is currently operating at a relatively small scale, with roughly a dozen active consultants or similar billing relationships.

Historically, the company operated at a larger scale and had more staff handling recruiting, HR, invoicing, payment tracking, and administration.

Because the business is smaller today, several workflows that could be handled through software are instead performed manually.

## Current Accounting / Billing Environment

Icon currently uses **QuickBooks Desktop**.

The company has historically used QuickBooks for invoicing and accounting, but some operational tracking is also done in spreadsheets and email.

The project team is considering whether moving to **QuickBooks Online** is appropriate because the project objective includes programmatically creating client invoices.

The coding agent should treat the business requirement as:

> The system must produce accurate client invoices from approved consultant timesheets and integrate those invoices into the company's accounting workflow.

The exact technical approach is intentionally left open.
