# Project Context

This folder contains business and product context for a coding agent that will build an AI-enabled workflow for Icon Technologies.

The goal of these files is to explain:
- what Icon Technologies does,
- the current business process,
- the workflow being optimized,
- the project objectives,
- important business rules and edge cases,
- and what success should look like.

These files intentionally avoid prescribing software architecture, implementation details, frameworks, infrastructure, or coding approaches. The coding agent should make those decisions independently.

## Files

- 01_business_context.md — What Icon Technologies does and how its staffing business works.
- 02_current_business_process.md — End-to-end staffing and back-office process, with emphasis on manual work.
- 03_project_scope_and_objectives.md — The exact workflow this project will automate and the agreed objectives.
- 04_business_rules_and_edge_cases.md — Important real-world rules, exceptions, and failure cases the system must understand.
- 05_data_and_entities.md — The business entities and information the workflow operates on.
